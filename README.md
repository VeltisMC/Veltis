# VeltisMC

VeltisMC is a standalone Minecraft server software built from the ground up with a focus on performance, simplicity, and modern architecture.

Unlike traditional Minecraft server software, VeltisMC is not based on Bukkit, Spigot, or Paper APIs.

## Goals

- High performance
- Multithreaded world management
- Simple and powerful plugin API
- Stable and reliable server architecture
- Modern developer experience
- Better utilization of modern hardware

## Status

VeltisMC is currently under active development.

The project is still experimental and APIs may change as development continues.
